# TRAIN OPERATOR ─ 小田原線 新宿—新百合ヶ丘 運転シミュレーター

**▶ 遊ぶ: https://esma-dev-studio.github.io/train-operator-odawara/**

実在路線の線形データの上を走る、本格志向のブラウザ電車運転シミュレーターです。
国土数値情報(N02)の実線形から生成した**本物のカーブ・勾配・駅間距離**を、
ワンハンドルマスコンと ATS-P型風の保安装置で運転します。装飾やキャラクターを排した
「運転士の仕事の再現」志向(BVE Trainsim系)のつくりです。

- 区間: 小田原線をモデルにした **新宿 — 新百合ヶ丘 21.6km・23駅**(駅名は実名)
- 車両: 通勤型8両(架空車。P4〜P1/N/B1〜B7/非常のワンハンドル)
- 対応: PC(キーボード)/タブレット(画面レバー)。WebGL必須

## 遊び方

1. 種別を選ぶ — **各駅停車(23駅/59分)・急行(8駅/42分)・快速急行(5駅/36分)**
2. 天候(晴れ/雨=粘着低下)と出発駅(途中駅からの区間運転も可)を選んで出庫
3. 出発時刻になるとドアが閉まる → ノッチを入れて発車
4. **↑/W**=ノッチ進め ↓/**S**=戻し **N**=切 **Space**=非常 **H**=警笛 **P/Esc**=一時停止
5. 停止位置目標(「8」の標識)にぴたりと停める。±35cmで「見事」
6. 全区間を走破すると**運転成績票**(停止精度30+定時30+遵守25+乗り心地15=100点)

## リアル志向の中身

- **実線形**: 国土数値情報の路線ポリラインを5m間隔4351点にリサンプル。曲率から
  61の曲線速度制限を自動生成(代々木八幡の連続カーブ等が実際に効く)。標高は
  国土地理院APIから取得し±25‰にクランプした縦断面(百合ヶ丘の登り勾配など)
- **挙動**: 起動加速3.3km/h/s+特性域逓減、ブレーキ込め/緩めの応答遅れ、勾配・走行抵抗、
  雨天粘着低下(滑走表示)、ジャーク計測(乗り心地評価)
- **保安装置**: 曲線・停止信号・停止位置への**照査パターン**を常時計算。接近チャイム→
  超過で常用最大ブレーキが自動介入(評定減点)。実物同様の+2km/h設計余裕つき
- **信号**: 閉塞信号+出発信号。3分前を走る**仮想先行列車**で現示(G/YG/Y/R)が変わる
- **ダイヤ**: 物理エンジンでの実走から自動校正した5秒刻みダイヤ。遅れは秒単位で評価
- **3D前面展望**: PBR材質+**HDRI空による環境光**(実写由来)+**太陽光と影**+ACES色調で描画。
  バラスト・草・コンクリートは実写系CC0テクスチャ、レールは金属光沢+断面、枕木は実体表示。
  沿線には**防音壁・金網フェンス・並木**、駅は点字ブロック・側壁・屋根柱まで作り込み。
  実カーブに沿う架線柱/吊架線+ハンガー、駅名標(隣駅表示つき)、制限標・解除標、
  **代々木上原〜登戸の複々線**(隣を走る列車)、**東北沢〜世田谷代田の地下区間**
  (下北沢の地下ホーム・トンネル照明・前照灯)、**多摩川橋梁**(トラス+橋桁)、
  新宿の高層ビル群→郊外→丘陵と変わる街並み(手続き生成)。雨天は濡れた道床・
  レール反射に加えて**フロントガラスの水滴とワイパー**を表現
- **画質設定**: 高/中/低の3段階(選択画面)。fpsが持続的に低い場合は
  解像度→影の順で**自動的に軽量化**
- **音**: すべてWebAudio合成 — 速度でキャリアが変わるVVVF音、走行音、25m毎の
  ジョイント音(タタン)、ATSチャイム、ドアチャイム、二音警笛
- **成績票**: 駅ごとの停止誤差(cm単位)と遅延の一覧、ランクS〜D、運転士級の称号、
  自己ベスト保存(localStorage)

## 権利・出典

- 線形・駅位置: **国土数値情報(鉄道データ N02-24)**(国土交通省) / 標高: **国土地理院 標高API**
- 描画: three.js (MIT License) をローカル同梱
- 空(HDRI): **Poly Haven**(CC0) / 地面・道床等のテクスチャ: **ambientCG**(CC0)
- 本作は個人制作の非公式シミュレーターであり、鉄道事業者とは関係ありません。
  社名・ロゴ・実車デザインは使用せず、車両・ダイヤ・信号配置は架空です。
  駅名・路線形状は公共データに基づく事実情報として使用しています

## ファイル構成

| パス | 責務 |
|---|---|
| `data/line.json` | 線形(5m間隔)・駅・制限・勾配・区間情報(事前生成) |
| `data/timetable.json` | 校正済みダイヤ(3種別) |
| `sim/engine.js` | 物理・ATS・信号・評定エンジン(**DOM非依存**・Node単体テスト可) |
| `scene/scene.js` | three.js 前面展望(線路・駅・信号・街の手続き生成) |
| `cab/cab.js` | 運転台計器盤(針式速度計・TIMS・表示灯) |
| `audio/audio.js` | WebAudio合成音 |
| `tools/preprocess.mjs` | N02→line.json 事前処理 |
| `tools/autodrive.mjs` | 自動運転ボット回帰テスト+ダイヤ校正(`--calibrate`) |

## 開発用デバッグ

`index.html?debug=1` で `window.__test` が有効:
`__test.fast(40)`=シミュレーション倍速 / `__test.auto(true)`=自動運転 /
`__test.app.sim` でエンジン直接操作。回帰は `node tools/autodrive.mjs [local|exp|rapid]`
(3種別とも完走・ATS照査0回を確認済み)。
