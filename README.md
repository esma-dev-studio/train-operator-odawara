# TRAIN OPERATOR ─ 小田原線 新宿⇔新百合ヶ丘 運転シミュレーター

**▶ 遊ぶ: https://esma-dev-studio.github.io/train-operator-odawara/**
（iPadは Safari の共有メニュー →「ホーム画面に追加」で全画面アプリになり、電波がなくても遊べます）

実在路線の線形データの上を走る、本格志向のブラウザ電車運転シミュレーターです。
国土数値情報(N02)の実線形から生成した**本物のカーブ・勾配・駅間距離**を、
ワンハンドルマスコンと ATS-P型風の保安装置で運転します。見た目は業務機器調、
文言は小学2年生でも読めるやさしい言葉(難しい漢字にはふりがな)にしています。

- 区間: 小田原線をモデルにした **新宿 ⇔ 新百合ヶ丘 21.6km・23駅**(駅名は実名)。**くだり・のぼり**両方向
- 車両: 通勤型8両(架空車。P4〜P1/N/B1〜B7/非常のワンハンドル)
- 対応: PC(キーボード)/iPad・タブレット(画面レバー)。WebGL必須

## 遊び方

1. タイトルの「運転をはじめる」→ **くだり/のぼり** と **種別**(各駅停車・急行・快速急行)を選ぶ
2. 路線図で **スタートの駅 → ゴールの駅** をタップ(「みじかく(2えき)」なら数分で遊べる)
3. **じかん**(ひる/ゆうがた/よる)と **天気**(はれ/あめ/ゆき)を選んで出発
4. ドアが閉まったらレバーで発車。**↑/W**=すすむ **↓/S**=ブレーキ **N**=切 **Space**=非常
   **H**=警笛 **C**=視点きりかえ **M**=消音 **P/Esc**=一時停止。
   タッチでは **すすむ/ブレーキ** ボタンを押したとたんに1段動き、**押したままにすると1段ずつ続けて**動く。
   ドアが開いているあいだに すすむ を入れておくと、ドアが閉まったところで なめらかに動き出す
5. 停止位置目標「8」にぴたりと停める。近づくと画面の「8」の **目印** が停止位置を指し(380m〜25m)、
   画面右の **ブレーキめやす** が「このままのブレーキだと どこに止まるか」を教えてくれる。
   ±35cmで「◎みごと」→ その駅の **えきスタンプ** がもらえる(±10cmは とくべつな音)
6. 手前すぎで止まっても 8秒のあいだに少し進めば止めなおせる(ブレーキをゆるめるたびに待ちなおす)。
   大きく行きすぎたら **「もういちど とめる」** で その駅の180m手前から やりなおせる(それまでの駅の点はそのまま。
   その駅の停止の点は少しへる)
7. ゴールで **運転成績票**(停止精度30+定時30+遵守25+乗り心地15=100点)と **くんしょう**

## 中身

### 運転(sim/ — DOM非依存・Nodeで単体テスト可)
- **実線形**: 国土数値情報の路線ポリラインを5m間隔にリサンプル。曲率から61の曲線速度制限を
  自動生成、標高は国土地理院APIから。のぼりは線形を丸ごと反転して同じエンジンで走る(`sim/line.js`)
- **挙動**: 起動加速3.3km/h/s+特性域逓減、ブレーキ込め/緩めの応答遅れ、勾配・走行抵抗、
  雨・雪の粘着低下(滑走)、ジャーク計測(乗り心地)
- **保安装置**: 曲線・信号・停止位置への照査パターンを前方3km先まで常時計算。超過で常用最大ブレーキ
- **信号**: 閉塞信号+出発信号。5分前を走る仮想先行列車で現示(G/YG/Y/R)が変わる
- **停止位置予測**: いまのノッチを保持したときの停止位置を物理モデルで先読み(誤差0.6m以内)
- **ダイヤ**: 自動運転ボットの実走からくだり/のぼり×3種別を自動校正(`tools/autodrive.mjs --calibrate`)

### 3D(scene/ — three.js)
- **3D運転台**: 窓枠・天板・サンバイザー・ワイパー(雨の日は動き、水滴を拭き取る)
- **視点**: 運転席/うしろから/よこから/線路わきから/そらから。外から見ると自分の8両編成が走る
- **ほかの列車**: 対向列車(各停は駅に停車)、複々線区間で急行線を追い抜いていく列車
- **沿線**: 新宿の頭端式ターミナル(駅ビル下のホーム・車止め・発車待ちの電車)、代々木上原〜登戸の
  複々線、東北沢〜世田谷代田の地下区間、多摩川橋梁、多摩丘陵の起伏と雑木林、踏切(遮断機・
  待っている車)、ホームで待つ人々、駅名標・吊り下げ案内、駅ごとのランドマーク(鳥居・観覧車など)
- **時間と天気**: ひる/ゆうがた(大気散乱の夕焼け・長い影)/よる(星と月の夜空・街明かり・窓明かり・前照灯・ブルーム)、
  はれ/あめ(雨のすじ・ぬれて暗く光る地面や壁)/ゆき(屋根や木の上・道床に積もる雪・雪原・降雪)。
  トンネルやターミナルでは目の慣れ(約1秒)で明るさがなじむ
- **描画**: PBR+HDRI環境光+太陽影+ACES。時間帯×天気ごとの光・霧・ブルームの数値は `scene/look.js` の表に集約。
  霧の色は空の地平線の色から計算し、遠景は霧の終わりで打ち切る(描画数を3〜6割削減)。
  広い沿線を約700mごとに分割して画面外を描かない(三角形数を約1/5に)。遠景クリップより遠い区切りは
  判定ごと省く。中・高画質はいつも「ブルーム用の描画先→出力」の1本の道で描く(シェーダが1組で済み、
  ブルームの入り切りでコンパイルが起きない)。影は何かが動いているときだけ描きなおす(駅で止まっている間・
  メニューの背景では前の影のまま)。空のHDRは背景を立方体に変換し、環境光は縮めた版から作って元の画像は捨てる
  (GPUメモリ約50MB減)。くもりの空は あめ・ゆき を選んだときに読みこみ、届くまでは青空のグラデーションで代わりをする
- **カクつかない工夫(iPadのSafari向け)**: シェーダの準備は走り出す前の暗転中に、材質ごとに
  「作る→GPUを待つ→三角形1つだけ描く」を12msずつに分けて行い(並行コンパイルのないSafariでも画面が止まらない)、
  ワールドの作り直し(起動・のぼり/くだりの切替)も1手順ごとに1コマゆずる。動かない物の行列は作ったあとに固め
  (毎フレームの行列計算を約85%削減)、GPUが2コマ以上おくれたらそのコマは描かない。
  自動画質は CPU と GPU のどちらが重いかを見分けて下げ(CPU: 遠くを描く距離・影の間引き / GPU: 解像度・にじみの解像度)、
  軽く動く端末では解像度・影を1段ずつ上げる(重ければもどして覚える)。夜のブルームは止めない。
  WebGLの文脈が消えても(ホーム画面アプリが裏で回収されたとき)、ステージを作りなおして同じ場面にもどる

### 音(audio/ — すべてWebAudioで合成。録音素材なし)
- AudioWorkletで3相PWMを1サンプルずつ計算する**VVVFインバーター音**(非同期→同期→1パルス)
- 走行音・25m毎のジョイント音(台車ごとの「タタン」)・曲線のきしり・空気ブレーキ・ドア・
  コンプレッサー・トンネル残響・踏切・すれ違い列車・雨音
- 駅ごとに違う**オリジナル発車メロディ**(8曲)、音声合成による**車内放送**(「つぎは…」「まもなく…」)。
  「はやく しゅっぱつ」でもメロディは鳴らしてからドアを閉める
- 停車の判定チャイム(±10cmは4音の とくべつな音)、終点のゴールの音、「いま！ブレーキ」の短い合図
- レバーの段ごとの手ごたえの音(「カチャ」。段で高さが変わり、非常は重い音)
- 波形の計算(`audio/synth.js`)は起動直後に**別スレッドのワーカー**(`audio/synth-worker.js`)で先回りして行い、
  描画やタップを止めない(ワーカーが使えないブラウザではメインスレッドで少しずつ)
- 試聴用ページ: `tools/audio-test.html`

### 遊びの要素
- **えきスタンプ**: 23駅それぞれの名物をモチーフにしたオリジナル図柄。帳面で集めた数がわかる
- **くんしょう**: 「ぴったり名人」「あんぜん運転」「ゆきの日の運転士」など20種
- **自己ベスト**: 種別×方向×天気ごと(全区間を走ったとき)

## 権利・出典

- 線形・駅位置: **国土数値情報(鉄道データ N02-24)**(国土交通省) / 標高: **国土地理院 標高API**
- 描画: three.js r160 (MIT License) と同梱の examples/jsm(ブルーム・出力パス・太い線)をローカル同梱
- 空(HDRI・はれ/くもり): **Poly Haven**(CC0) / 夕焼けの空(大気散乱モデル)と夜空(星・月)はプログラムで生成 /
  地面・道床等のテクスチャ: **ambientCG**(CC0)
- 本作は個人制作の非公式シミュレーターであり、鉄道事業者とは関係ありません。
  社名・ロゴ・実車デザインは使用せず、車両・ダイヤ・信号配置・発車メロディ・スタンプ図柄は架空・オリジナルです。
  駅名・路線形状は公共データに基づく事実情報として使用しています

## ファイル構成

| パス | 責務 |
|---|---|
| `data/line.json` | 線形(5m間隔)・駅・制限・勾配・区間情報(事前生成) |
| `data/timetable.json` | 校正済みダイヤ(くだり3種別+のぼり3種別 `*_up`) |
| `sim/engine.js` | 物理・ATS・信号・評定・停止位置予測(**DOM非依存**) |
| `sim/line.js` | 線形の方向変換(のぼり反転・新宿ターミナルの余白) |
| `sim/autopilot.js` | 自動運転(回帰テスト・校正・タイトルのデモ走行で共用) |
| `scene/scene.js` | three.js ワールド(線路・駅・信号・街・地形の手続き生成、カメラ、天候、ブルーム) |
| `scene/look.js` | 時間帯×天気の光・霧・ブルームの表、ぬれ/雪の共通シェーダ部品、夜空 |
| `scene/cockpit.js` / `trains.js` / `traffic.js` / `weatherfx.js` | 3D運転台 / 車両モデル / ほかの列車 / 雨雪 |
| `cab/cab.js` | 運転台計器盤(針式速度計・TIMS・表示灯・レバー) |
| `audio/audio.js` / `vvvf-worklet.js` / `announce.js` | 合成音 / VVVF / 車内放送 |
| `audio/synth.js` / `synth-worker.js` | 効果音の波形合成(DOM非依存) / それを別スレッドで動かすワーカー |
| `ui/stamps.js` / `badges.js` / `rainglass.js` | えきスタンプ / くんしょう / ガラスの水滴 |
| `ui/stoppin.js` / `loadroute.js` / `glguard.js` | 画面の「8」の目印 / よみこみ画面の路線の帯 / WebGLの文脈が消えたときの立ちなおり |
| `sw.js` / `manifest.webmanifest` | オフライン対応・ホーム画面アプリ化 |
| `tools/preprocess.mjs` | N02→line.json 事前処理 |
| `tools/autodrive.mjs` | 自動運転ボット回帰テスト+ダイヤ校正 |
| `tools/e2e.mjs` | ブラウザ通しテスト(タイトル→区間運転→成績票→行きすぎのやりなおし→文脈の消失→長い処理の記録) |
| `tools/shots.mjs` | 決まった40場面のスクリーンショットと描画負荷(calls.json: draw call・三角形・シェーダ数・影のdraw call) |
| `tools/check-sw.mjs` | オフライン用の保存一覧(sw.js の CORE)に漏れがないか |

## 開発用

- エンジン回帰: `node tools/autodrive.mjs local|exp|rapid [clear|rain|snow] [up]`
  (くだり/のぼり×3種別×3天候の18通りで完走・ATS照査0を確認済み)
- ブラウザ通し: `npx http-server -p 8123 -c-1 .` のあと `node tools/e2e.mjs`
- 場面のスクリーンショット: `node tools/shots.mjs <出力フォルダ> [場面名の一部...]`(`BASE=` `Q=low|mid|high`)
- `index.html?debug=1` で `window.__test`: `fast(倍率)` / `auto(true)` / `setup({service,dir,start,end,weather,daytime})` /
  `cam('chase')` / `redraw()` / `fadeCard(true)` / `loseGL()`。`&q=low|mid|high` で画質を指定。
  `?debug=1` では、固めた(動かないはずの)物が動くと `[freeze] frozen object moved` を出す
  (作ったあとに動かす物には `userData.dyn = true` を付ける)
